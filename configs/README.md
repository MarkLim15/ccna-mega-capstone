# Device Configuration Examples

The current project includes the complete Packet Tracer lab file, [`ccna-mega-capstone.pkt`](../ccna-mega-capstone.pkt), which can be opened to inspect and test the device configurations.

This folder is reserved for optional, readable IOS configuration snapshots if I choose to expand the portfolio later. They are not required to use the included lab. If I publish snapshots, I’ll redact passwords, secret hashes, and any other sensitive values. Any examples are for learning and review, not drop-in production configurations.
